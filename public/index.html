Capture web pages as PNG
from the command line

Browsershot is a free, open-source tool that saves a page, or one visible element, as a PNG. Click through the page first if you need to, then read the result as an image, a JSON object, or both.

Get started View on GitHub

A capture in one command:

browsershot https://example.com

What it does

  • Pages or components

    Capture the whole page with --full-page, or only the first visible element that matches a selector. Group and label the output so a set of captures stays organised.

  • Actions before the shot

    Wait for an element, then click, type, hover or press a key, and check the page with --expect-text before anything is written.

  • Inspection and JSON

    --inspect records an element and writes a sidecar next to the image; --json prints one result object for scripts and coding agents.

  • Saved pages and defaults

    Keep a route, selector and setup in .browsershot/, then recapture a known view by name instead of rebuilding the command.

  • Storybook and Ladle

    Register a running component environment once and capture any example by name, matched against that environment's own catalog.

  • Errors and sign-in

    Collect browser console errors and uncaught exceptions beside the PNG, and sign in to a protected page through Authstate when you need to.

Examples

Run these from the application directory with its server already running, or pass a complete URL instead of a route.

Install from source

Browsershot is not installed by a single command. You need Bun and Git, then a Chromium download and a local build, and the first capture prints the PNG path to stdout. The Get started section of the README has the exact steps, including the Linux variant that installs Chromium's system dependencies.

No frameworks, no third-party fonts, no build step.
